# Enigma

Material de producción para el canal **Enigma**: misterios, enigmas sin resolver e historia oculta.

## Contenido

- Videos terminados (Shorts y videos largos), listos para subir.
- `short-*.mp4`: Shorts terminados.
- Formato "mascota + palabra a palabra": skill en `.claude/skills/short-mascota/`, script `tools/mascota_short.py`, mascota en `mascota/`, proyectos en `proyectos/` (ejemplo: `proyectos/bermudas/`).
